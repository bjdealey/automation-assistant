# knowledge/best-practices/

Engineering standards for A360 bots — the bar we design and review against.

- **`a360-engineering-standards.md`** — the consolidated standards (structure,
  reliability, maintainability, security, observability, performance,
  testability).

These are **best-practice candidates** grounded in general software/automation
engineering, not claims about platform behaviour. Where a standard depends on an
A360 capability, that capability must be `CONFIRMED` separately in
`../platform/`.
