# knowledge/organisation/

The organisation's own vocabulary, conventions, and standards — learned from the
corpus and from the team. This is where "how *we* do it" lives.

**Organisation convention ≠ platform fact.** Record these as
`organisation-convention` (or the appropriate corpus classification), not as
A360 truth.

Suggested files:
- `naming-conventions.md` — bots, sub-bots, variables, files, folders.
- `variable-conventions.md` — casing, prefixes, input/output marking.
- `folder-structure.md` — how bots are organised in the Control Room / repo.
- `reusable-components.md` — shared sub-bots and where they live.
- `error-handling-standard.md` — the org's standard approach (if any).
- `logging-standard.md` — where/how the org logs.
- `glossary.md` — domain and system terms used in bot names and comments.

Populate this from `03-bot-corpus-analysis` output; cite the bots that evidence
each convention and note how consistently it is followed.
